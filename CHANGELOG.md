# Changelog

## 0.2.0

- Add HSV conversion, RGBA parsing/composition, mixing and palette helpers.
- Add linear-light and multi-stop gradients with bounded input sizes.
- Add measured contrast suggestions with explicit pass/fail and change flags.
- Add a complete `cmd/audit` workflow covering valid, invalid and unreachable cases.
- Add independent numeric fixtures alongside round-trip and regression tests.
- Expand to 30 library tests per backend; retain the standalone consumer.
- Document scope relative to existing MoonBit color libraries without claiming
  unmeasured performance advantages or unique ecosystem capabilities.

## 0.1.0

- Initial validated RGB/HEX/HSL conversion and WCAG text contrast utilities.
