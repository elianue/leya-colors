# Leya Colors

**A lightweight color utility library built with MoonBit.**

Leya Colors is an open-source project designed to provide simple, reliable, and reusable color processing tools for developers and designers.

The project focuses on color format conversion, accessibility calculations, and developer-friendly APIs.

## Project Overview

Color plays an important role in digital design, web development, and user experience.

However, developers often need to implement repetitive color calculations, including format conversion and contrast checking.

Leya Colors aims to simplify these tasks by providing a lightweight, reusable library written in MoonBit.

The project also aims to contribute practical utilities to the growing MoonBit open-source ecosystem.

## Planned Features

### 1. Color Format Conversion

- HEX to RGB conversion
- RGB to HEX conversion
- RGB to HSL conversion
- HSL to RGB conversion

### 2. Color Accessibility

- Calculate relative luminance
- Calculate contrast ratios between two colors
- Check color contrast against WCAG accessibility guidelines
- Evaluate text readability against background colors

### 3. Developer-Friendly API

- Simple and reusable functions
- Clear function naming
- Input validation and error handling
- Easy integration into MoonBit projects

### 4. Testing and Documentation

- Unit tests for core functions
- Example usage for each major feature
- API documentation
- Instructions for installation and testing
