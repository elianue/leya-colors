# 初审问题整改说明

针对截图中“有效 MoonBit 源码量不足 500 行”的反馈，本次补充可独立调用的颜色处理功能，并提供测试与可复现统计。此文档随整改源码一同提交至 GitHub，报名表仍需更新后重新提交。

## 实际功能

- `hsv.mbt`：HSV 参数校验、RGB/HSV 双向转换、HSL/HSV 直接转换，避免中途量化。
- `alpha.mbt`：RGBA 校验、RGBA/RRGGBBAA 解析与输出、source-over 合成、在不透明底色上展平后计算对比度。
- `palette.mbt`：sRGB/线性光混色、渐变、色相旋转、互补色/三角色/类似色、明度/饱和度调整、前景选择、调色板对比度审计。
- `stops.mbt`：有序多色标渐变、指定位置采样、离散搜索对比度改善建议。
- 原有 HEX/RGB/HSL 和 WCAG 对比度 API 保留。

## 边界约定

透明合成采用编码 sRGB 通道算术，每次合成后量化为 8 位；不等同于线性光合成。`MixSpace::LinearRgb` 则在线性光空间插值。渐变最多 4096 色，审计与多色标最多 256 项。

`suggest_foreground` 在朝黑色和白色的 255 步路径上寻找第一个满足要求的结果。若背景使 AAA 普通文本目标不可达，则返回黑白中对比度更高的一项；调用方仍需用 `passes_contrast` 检查。它不保证感知色差最小。
